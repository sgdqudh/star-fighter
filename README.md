# 星空战机

竖版 9:16 的星空射击小游戏，纯前端实现（HTML + CSS + 原生 JavaScript），
**零第三方依赖、零构建步骤、无需联网**，打开网页即玩。

## 在线游玩

- 多文件版（首页）：`index.html`
- 单文件版（可单独下载分享）：`game.html`

## 操作

| 操作 | 键盘 / 手势 |
| --- | --- |
| 移动战机 | 方向键 / `W` `A` `S` `D`；手机可直接拖动屏幕 |
| 自动射击 | 无需操作（初始 3 发/秒，可通过升级强化） |
| 通用确认 | `空格` |
| 暂停 / 继续 | `ESC`，或点右上角方形按钮 |
| 升级三选一 | 点卡片，或按 `1` `2` `3` |

## 玩法概要

- 击毁敌机获得分数与经验（小型 10 / 中型 30 / 精英 80），**累计经验自动升级（最高 8 级）**；
- 每次升级从 **3 个随机强化**中选 1 个：射速提升、火力增强、额外弹链（最多 4 发）、移速提升、生命上限、减伤护盾，同类叠加数值递减；
- 难度按累计得分分三档推进（0–5000 新手友好期 / 5000–12000 稳步提升期 / 12000+ 高压挑战期），
  敌机血量、移速、生成密度、精英刷新与弹幕密度逐档提高；
- 击毁敌机有 15% 概率掉落道具：火力强化、生命恢复、护盾、射速强化、全屏炸弹；
- 累计 **15000 分**召唤最终 BOSS：120 点血、三类独立冷却召唤、半血狂暴（弹幕频率 +35%）、
  血量首次降到 25% 时单次回血 30 点；击败它即通关。

单局时长约 **8~10 分钟**。

## 技术要点

- 画面全部由 **Canvas 2D 程序化绘制**，没有任何图片素材；
- 音效与背景音乐全部由 **WebAudio 实时合成**，没有任何音频素材；
- 因此整个游戏只有几十 KB，且天然适合静态托管。
